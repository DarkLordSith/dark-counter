# Public Pixel

Pixel font for headings and numbers in «Тёмный прилавок».

- Author: GGBotNet — https://ggbot.itch.io/public-pixel-font
- Version: 1.24 (from the font's `name` table)
- License: Creative Commons Zero v1.0 Universal (CC0, public domain) — https://creativecommons.org/publicdomain/zero/1.0/
  No attribution required; credited here anyway.
- Files: `PublicPixel.woff2` and `PublicPixel.ttf`, the author's originals, unmodified.
- Glyphs: 8×8 grid, monospaced, Latin + full Cyrillic (incl. Ё, Й, Щ, Ъ, Ы, Э, Ю, Я, №).
  Use sizes that are multiples of 8px (8, 16, 24), otherwise the pixels blur.
  Not in the font: ★ ☾ ♪ ⚙ ⟲ — the browser takes them from the next font in the stack.
