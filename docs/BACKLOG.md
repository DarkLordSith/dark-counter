# Тёмный прилавок — бэклог

> Этот файл — основной план разработки. Обсуждения идей ведутся с Claude в проекте «Тёмный прилавок» на claude.ai, итоги переносятся сюда.
> Порядок работы задаёт раздел **«План»**. Задачи берём сверху вниз, по PR на задачу.

Личный проект, вдохновлённый Probably Stolen, для телефона и Mac. Цели: показать друзьям (в том числе англоязычным), придумать своё лицо игры. Денежный релиз пока не планируется.

Игра: darklordsith.github.io/dark-counter/ (PWA на GitHub Pages).
Сохранение лежит в localStorage под ключом `dark-counter-v3`. Перенос — через кнопку «сейв» (код `DC1:` + base64 JSON).

## Баги и техдолг — детали
- **HUD под статус-баром в установленной PWA на iPhone.** Верхняя строка уходит под часы и размывается.
  - Проверено: отступ `env(safe-area-inset-top)` не терялся. Он есть и до миграции, и в сборке. Проблема в `black-translucent`: страница рисуется под полупрозрачным статус-баром, и защиту держит только `env()`.
  - Фикс (PR «фикс HUD под статус-баром»): `apple-mobile-web-app-status-bar-style: black`. Статус-бар непрозрачный, страница начинается под ним.
  - Проверять на реальном iPhone или в iOS Simulator: в Chrome-эмуляции safe-area равна нулю.
  - **12.11.2026: фикс `black` не помог** на iPhone даже после переустановки PWA (сборка `3a606cc` дошла). Вероятная причина — регрессия WebKit с iOS 26.1 (bug 301994, на iOS 27.2 ещё открыт): в установленных PWA meta статус-бара игнорируется, `env(safe-area-inset-top)` может быть 0, системный полупрозрачный бар перекрывает контент.
  - Устройство владельца: iPhone 12, iOS 27 — версия с открытым багом.
  - Следующий шаг: диагностическая панель (standalone, inset-top, `innerHeight`/`screen.height`, `visualViewport`) → по данным запасной отступ для iOS-PWA, когда inset = 0.
  - Любая смена `apple-mobile-web-app-*` meta требует переустановки PWA у игроков.
  - **Скрин 12.11.2026 (iPhone 12, iOS 27):** safe-area работает, HUD начинается с ~48 pt. Но системная размытая полоса iOS 26+ тянется до ~78–80 pt и размывает HUD и ряд кнопок. Из CSS/meta не отключается.
  - **Решение:** декоративная полоса «потолок станции» высотой ~32 pt под статус-баром, только в iOS-PWA (`navigator.standalone`). Без текста и кнопок: всё в этой зоне размыто. Высота в CSS-переменной, подкрутить по диагностике и на моделях с Dynamic Island. Перенос HUD вниз — рассмотреть в «Графике v1».
  - 13.11.2026: 32px мало — HUD частично в размытии; поднято до 56px, ждём подтверждения на iPhone.
- **Чистая экономика:** `state` и `rng` (`() => number`) параметрами вместо глобальных (`offerToSeller(state, price, rng)`).
  - Проще тесты, воспроизводимые баги по сиду, сценарный пролог на фиксированном сиде.
  - Поведение не меняется, проверка стендом паритета.
- **`RARE_FINDS` зависит от порядка:** флаг `rare: true` в каталоге, запасная иконка для товара без спрайта, TS проверяет полноту `ITEM_SPRITES`. Это намеренная смена поведения.
- **Музыка замедляется, когда окно скрыто.** Браузер троттлит `setInterval` планировщика. Фикс: тик в Web Worker, по `visibilitychange` lookahead ~1,5 с.
- **Сейв слишком длинный** (день 25 — 5 804 символа). 76% объёма — лента событий. Фикс:
  - в сейв класть 5–10 последних строк ленты;
  - сжатие через `CompressionStream('deflate-raw')`, формат `DC2:`, `DC1:` продолжает загружаться;
  - кнопка «скачать сейв файлом».
  
  Замер: 744 символа (−87%). Ленту хранить как ключ + параметры (см. «Локализация»).
- **Непропорциональные тела персонажей:** см. «Графика v1».
- Риск: Safari может удалить данные сайта, если его долго не открывать. Позже — IndexedDB и `navigator.storage.persist()`.

## Локализация RU / EN
Цель: переключатель языка, чтобы играли англоязычные друзья. Делать до контента, чтобы каждая новая строка сразу шла через словари.
- **Словари:** `src/i18n/ru.ts` (эталон) и `en.ts`, функция `t('key', {params})`. `en` объявлен через `satisfies` по типу `ru`: сборка падает, если в английском не хватает ключа.
- **Множественное число:** `Intl.PluralRules`. В русском 3 формы, в английском 2.
- **Числа:** `Intl.NumberFormat`.
- **Язык:** настройка в отдельном ключе localStorage, не в сейве. По умолчанию — `navigator.language`. Переключатель в меню.
- **Лента событий:** ключ + параметры, а не готовая строка.
- **Пиксельный текст на canvas** (неон «ЛАВКА 7Б»): латинские глифы и английский вариант вывески.
- **Шрифты:** display-шрифт должен поддерживать и кириллицу, и латиницу.
- **Имена и название игры:** решить в дизайн-документе (Grobov или адаптированное имя).
- **Тесты:**
  - полнота ключей;
  - в `en` нет кириллицы;
  - длинные строки не ломают интерфейс на iPhone.
- **Процесс для нового контента:** RU → перевод Claude → проверка владельцем.

## Решения по геймплею
- Аренда раз в 7 дней. Сумма примерно ×2,5, рост медленнее. Плюс мелкие ежедневные расходы.
- Ветки развития смешанные:
  - навыки за опыт: Механик, Торговец, Тень;
  - оборудование за кредиты;
  - изучение артефактов открывает рецепты.
- События с сюжетным выбором и отложенными последствиями.
- Склад: верстак как нижняя шторка, компактная сетка, фильтры-чипсы.
- **Мобильный в приоритете:**
  - шторки и модалки поверх сцены;
  - постепенное раскрытие систем;
  - события по 2–3 строки;
  - на широком экране Mac панели стоят рядом со сценой.
  
  Для дерева навыков, рынка и корзины сразу делать мобильный макет.
- **Графика персонажей:** сначала код (пиксельные карты, модульные части, палитры, портреты), потом владелец рисует сам в Piskel или Aseprite. Система частей и палитр должна позволять подменить картинки.
- Phaser — позже, только для сцены, если появятся рисованные спрайты.
- Порт (Tauri, Capacitor) — только ради дистрибуции, до itch.io/Steam не нужен.

## Многотоварные сделки (черновик)
- **Покупатель, опт:** «энергоячеек на 400 кр.» или «5 энергоячеек». Ждёт оптовую скидку, возможна частичная продажа.
- **Покупатель, комплект:** «визор + ячейка». За полный комплект платит с бонусом.
- **Покупатель с условием:** «без краденого», «не ниже 70%».
- **Продавец, лот:** коробка из 3–5 вещей, цена за всё. Осмотр выборочный, каждая проверка съедает терпение.
- **Торг** за всю корзину: шанс по сумме, строка «итого / бюджет».
- **Интерфейс:** корзина на прилавке, тап по плитке склада добавляет или убирает вещь. Нужна склад-шторка из патча A.

## Своё лицо игры: «Долг отца» на падающей станции
- Отец погиб, оставил лавку на нижнем ярусе станции «Кольцо Б» и долг Гробову.
- Станция сходит с орбиты, через ~60 дней последний шаттл. Места распределяет Гробов.
- Цель: закрыть долг и купить место.
- Механики:
  - аренда превращается в еженедельный платёж по долгу;
  - индекс паники растёт к концу и раскачивает рынок;
  - сюжет раскрывает, что отец возил ИИ-чипы для Гробова.
- 3–4 концовки: улететь, остаться с чипом, сдать Гробова, занять его место.
- Риски:
  - таймер может давить, возможно нужен спокойный режим;
  - много текста, для начала 8–10 ключевых событий;
  - название под вопрос: «Последний рейс», «Нижний ярус», «Долг на орбите», плюс EN.

### Пролог: предыстория и обучение (черновик)
Принцип: учим делом, по одной механике за раз, без стен текста.
- **Интро**, 3–4 кадра:
  1. письмо о смерти отца;
  2. прилёт на станцию;
  3. пыльная лавка;
  4. Гробов: «Твой отец мне задолжал».
- **День 0:**
  1. Сосед-механик, друг отца (наставник), учит осмотру.
  2. Мутный тип со спиленным серийником: выбор и розыск.
  3. Жёсткий покупатель: торг и «Чуйка», первый отказ не наказывается.
  4. Сломанная вещь: верстак.
  5. Свалка с наставником: деталь отца, первая зацепка.
  6. Ночь: объявление «эвакуация через 60 дней», Гробов о платежах. Старт игры.
- **Техника:**
  - сценарные клиенты на фиксированном сиде;
  - подсветка кнопок;
  - системы открываются по ходу;
  - флаг `tutorialDone`, у старых сейвов пролог пропускается;
  - «Пропустить пролог».
