# Тёмный прилавок

Пиксельный киберпанк-симулятор лавки на космической станции. Это личный проект, вдохновлённый Probably Stolen. В планах своё лицо: сеттинг, название, крючок.
Игрок сидит за прилавком и делает пять вещей:
- зовёт клиентов;
- осматривает товар;
- торгуется;
- чинит и собирает вещи;
- вечером копает на свалке.

Аренду собирает ростовщик Гробов. Цель — выкупить лавку.

Владелец — джун фуллстак, мечтает о геймдеве. Объясняй решения коротко и по-русски: что сделал и зачем. Выбирай инструмент, который подходит задаче, а не «лишь бы работало».

## Стек
- **Vite + TypeScript** (strict), без UI-фреймворков. Интерфейс — HTML/CSS, сцена — `<canvas>`.
- **Vitest** для чистой игровой логики.
- **vite-plugin-pwa** (Workbox) для манифеста и service worker. Ручной `sw.js` не пишем.
- Деплой: GitHub Actions → GitHub Pages. `base: '/dark-counter/'` в `vite.config.ts`.
- Графика: canvas 160×100 логических пикселей, рисуем прямоугольниками: `fillRect(x,y,w,h,color)`, спрайты — списки `[x, y, w, h, color]` для `fillRects()`. Спрайты-картинки только после отдельного решения (тогда, возможно, Phaser для сцены).
- Звук: Web Audio API, генеративный лофи. Старт только по клику.
- Внешнее: Google Fonts (Silkscreen, IBM Plex Mono) с фолбэками.

## Команды
- `npm run dev` — разработка с hot reload.
- `npm run build` — продакшн-сборка в `dist/`.
- `npm run preview` — проверка сборки локально, в том числе PWA и офлайн.
- `npm test` — Vitest.
- `npm run typecheck` — `tsc --noEmit`.

## Структура
- `index.html` — разметка, подключает `src/main.ts`.
- `src/main.ts` — инициализация: загрузка сейва, связка модулей, рендер, цикл анимации.
- `src/types.ts` — `GameState`, `Item`, `ItemType`, `Customer` (размеченное объединение по `kind`: `'sell' | 'buy' | 'rent'`). Короткие поля сейва описаны с комментариями.
- `src/data.ts` — товары (`ITEM_TYPES`), рецепты (`RECIPES`), имена, реплики, все балансовые числа (`RENT`, `HAGGLE`, `DIG_ODDS`…). Новый контент добавляется здесь.
- `src/state.ts` — `state` (сейв), `ui` и `actor` (состояние экрана, не сохраняются), `newGame`, `createItem`, `saveGame`, `loadGame`, `migrate`, `exportSave`, `importSave`.
- `src/economy.ts` — торг (`sellerAcceptChance`/`buyerAcceptChance`, `perceivedChance`), аренда и залог (`planCollateral`), свалка (`digPile`), верстак (`useWorkbench`), сборка (`craft`), ночь (`sleepUntilMorning`). **Чистые функции без DOM.**
- `src/appearance.ts` — внешность клиента по сиду (`appearanceFor`). Чистая функция: её используют и `economy` (имя человека или робота), и `scene` (отрисовка).
- `src/scene.ts` — canvas: лавка, свалка, спрайты клиентов и товаров (`ITEM_SPRITES`), анимации, `startScene`.
- `src/ui.ts` — HUD, вкладки, панели, модалки, таблица обработчиков `ACTIONS` (кнопки несут `data-a`).
- `src/audio.ts` — лофи.
- `src/util.ts` — random и math-хелперы без игровой логики и без DOM.
- `src/dom.ts` — `byId` и другие DOM-хелперы для `ui` и `scene`; `markIosPwa()` ставит класс `ios-pwa` на `<html>` в установленной iOS-PWA (полоса «потолок станции»).
- `src/diag.ts` — отладочный оверлей для бага с отступом в iOS-PWA: долгий тап по подписи версии в окне «сейв». Читает DOM сам, подключается в `main.ts`, сейв и игру не трогает.
- `src/version.ts` — подпись версии в окне «сейв»: `__APP_VERSION__` (из `package.json`) и `__COMMIT_HASH__` (из git) подставляет Vite через `define` в `vite.config.ts`.
- `src/style.css` — стили, токены цветов в `:root`. Формат: один селектор и одно свойство на строку.
- `public/icons/` — иконки PWA.
- `tests/unit/` — Vitest: логика и сейв.
- `tests/fixtures/` — реальные коды сейвов прошлых версий.
- `tests/parity/` — стенд паритета: эталонная версия против кандидата в headless Chrome (см. его README). Гонять при рефакторинге и миграциях.

Правило: логика меняет `GameState` и возвращает результат. Например, `sleepUntilMorning()` возвращает события ночи, а всплывающие числа кладутся в очередь `feedback`. DOM трогают только `ui.ts` и `scene.ts` (через `dom.ts`). Без `any`; если тип неочевиден, описываем его в `types.ts`.
Импорты без циклов: `types`/`data`/`util` → `appearance` → `state` → `economy` → `scene` → `ui` → `main`.

### Новый товар
1. Одна строка в `ITEM_TYPES` в `src/data.ts`. Тип `ItemType` выводится из ключей каталога, правка в `types.ts` не нужна.
2. Иконка (по желанию) — запись в `ITEM_SPRITES` в `src/scene.ts`. Без неё товар рисуется без иконки.
3. Если товар должен попадаться как редкая находка, добавить ключ в `RARE_FINDS`. Порядок в этом списке влияет на случайный выбор, поэтому вывести его из каталога пока нельзя.

## Сохранения: не ломать
- Ключ localStorage: `dark-counter-v3`. Не менять без миграции.
- Код сейва: `DC1:` + base64(JSON). Старые коды должны загружаться всегда.
- Поля `GameState` (`day`, `inv`, `cust`, `llAt`, у предметов `t`, `k` и т.д.) — это формат сейва. Короткие имена не переименовываем ради красоты, а описываем в `types.ts`.
- Новое поле в `GameState` → значение по умолчанию в `migrate()`. Переименование или удаление поля → преобразование в `migrate()`.
- В `tests/fixtures/` лежат реальные коды сейвов прошлых версий. Тест обязан загружать каждый из них.

## UI
- Mobile-first: iPhone в портрете. Вся игра помещается в один экран, прокручивается только нижняя панель (`.pane`).
- Учитывать safe-area (`env(safe-area-inset-*)`). Кнопки не меньше ~36px по высоте.
- Тёмная палитра из токенов: `--bg`, `--panel`, `--cyan`, `--amber`, `--red`, `--green`. Без литеральных цветов в компонентах.
- Шрифты: `--display` (Silkscreen) для заголовков и меток, `--mono` для текста.
- Без `alert`, `confirm`, `prompt`: только свои модалки.

## Релиз
1. `npm run typecheck && npm test && npm run build` — всё зелёное.
2. `npm run preview` в мобильной эмуляции. Чек-лист:
   - клиент входит и уходит;
   - сделка проходит;
   - Гробов приходит в день аренды;
   - вечер и свалка работают;
   - сейв экспортируется и импортируется;
   - офлайн-запуск работает.
3. Работа в ветке → PR → мердж в `main` → Actions деплоит сам.
4. Коммиты по-русски, коротко: `торг: шанс согласия зависит от репутации`.
