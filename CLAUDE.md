# Тёмный прилавок

Пиксельный киберпанк-симулятор лавки на космической станции. Это личный упрощённый клон Probably Stolen.
Игрок сидит за прилавком и делает пять вещей:
- зовёт клиентов;
- осматривает товар;
- торгуется;
- чинит и собирает вещи;
- вечером копает на свалке.

Аренду собирает ростовщик Гробов. Цель — выкупить лавку.

Владелец — джун фуллстак. Объясняй решения коротко и по-русски: что сделал и зачем.

## Стек и ограничения
- Чистый HTML, CSS и JS. **Без фреймворков, без сборщика, без npm-зависимостей в рантайме.**
- Деплой: GitHub Pages из `main`, корень репо. Всё должно работать как статические файлы.
- Модули: нативные ES-модули (`<script type="module">`), относительные пути.
- Графика: `<canvas>` 160×100 логических пикселей, рисуем прямоугольниками: `fillRect(x,y,w,h,color)`, спрайты — списки `[x, y, w, h, color]` для `fillRects()`. Без картинок-спрайтов, пока не договорились иначе.
- Звук: Web Audio API, генеративный лофи. Включается только по клику пользователя.
- Внешнее: только Google Fonts (Silkscreen, IBM Plex Mono) с фолбэками.

## Структура
- `index.html` — разметка и подключение `js/main.js`.
- `css/style.css` — стили и токены цветов в `:root`. Формат: один селектор и одно свойство на строку.
- `js/main.js` — точка входа: загрузка сейва, связка модулей, старт цикла.
- `js/data.js` — товары (`ITEM_TYPES`), рецепты, имена, реплики, все балансовые числа. Новый контент добавляется здесь.
- `js/state.js` — объект `state` (бывший `S`), `saveGame`, `loadGame`, `migrate`, `exportSave`/`importSave`.
- `js/economy.js` — торг (`sellerAcceptChance`/`buyerAcceptChance`), аренда, свалка, верстак, сборка, ночные события.
- `js/scene.js` — отрисовка сцены, спрайты клиентов и товаров (`ITEM_SPRITES`), анимации входа и выхода.
- `js/ui.js` — рендер HUD, вкладок и панелей, модалки, таблица обработчиков `ACTIONS` (кнопки несут `data-a`).
- `js/audio.js` — лофи.
- `js/util.js` — random- и DOM-хелперы без игровой логики.
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA.

Логику держим отдельно от DOM: функции в `economy.js` меняют `state` и возвращают результат (например, `sleepUntilMorning()` возвращает события ночи), всплывающие числа кладут в очередь `feedback`, а рисует всё `ui.js`.
Импорты без циклов: `data`/`util` → `state` → `scene` → `economy` → `ui` → `main`.

### Новый товар
1. Одна строка в `ITEM_TYPES` в `js/data.js`.
2. Иконка (по желанию) — запись в `ITEM_SPRITES` в `js/scene.js`; без неё товар рисуется без иконки.
3. Если товар должен попадаться как редкая находка — добавить ключ в `RARE_FINDS`.

## Сохранения: не ломать
- Ключ localStorage: `dark-counter-v3`. Не менять без миграции.
- Поля `state` (`day`, `inv`, `cust`, `llAt`, у предметов `t`, `k` и т.д.) — это формат сейва. Короткие имена не переименовываем ради красоты.
- Код сейва: `DC1:` + base64(JSON `state`). Старые коды должны загружаться всегда.
- Новое поле в `state` → значение по умолчанию в `migrate()`. Переименование или удаление поля → преобразование в `migrate()`.
- Перед мерджем проверка: код сейва со старой версии загружается в новую, игра продолжается с того же дня.

## UI
- Mobile-first: iPhone в портрете. Вся игра помещается в один экран, прокручивается только нижняя панель (`.pane`).
- Учитывать safe-area (`env(safe-area-inset-*)`). Кнопки не меньше ~36px по высоте.
- Тёмная палитра из токенов: `--bg`, `--panel`, `--cyan`, `--amber`, `--red`, `--green`. Без литеральных цветов в компонентах.
- Шрифты: `--display` (Silkscreen) для заголовков и меток, `--mono` (IBM Plex Mono) для текста.
- Без `alert`, `confirm`, `prompt`: подтверждения делаем своими модалками (`openModal`).

## Релиз
1. Поднять `CACHE` в `sw.js` (`dark-counter-vN`). Новые файлы добавить в `SHELL`.
2. Проверить локально: `python3 -m http.server 8000`, открыть в мобильной эмуляции.
3. Чек-лист:
   - нет ошибок в консоли;
   - клиент входит и уходит;
   - сделка проходит;
   - Гробов приходит в день аренды;
   - вечер и свалка работают;
   - сейв экспортируется и импортируется.
4. Коммиты по-русски, коротко: `торг: шанс согласия зависит от репутации`.
