# Тёмный прилавок

Пиксельный киберпанк-симулятор лавки на космической станции. Это личный проект, вдохновлённый Probably Stolen.

Вы сидите за прилавком на нижнем ярусе станции. Зовёте клиентов, осматриваете товар, торгуетесь, чините и собираете вещи на верстаке. Вечером копаете на свалке, раз в несколько дней платите аренду ростовщику Гробову. Цель — накопить на выкуп лавки.

## Стек
- **Vite + TypeScript** (strict), без UI-фреймворков. Код в `src/`, подробная карта модулей в `CLAUDE.md`.
- Графика рисуется в `<canvas>` прямоугольниками, музыка генерируется через Web Audio API.
- PWA через `vite-plugin-pwa`: игру можно поставить иконкой на телефон и играть офлайн. Манифест и service worker генерируются при сборке.
- Прогресс хранится в `localStorage` браузера.
- Тесты: Vitest для логики и сейвов (`tests/unit`), стенд паритета поведения в headless Chrome (`tests/parity`).

## Запуск локально
Нужен Node 22.

```bash
npm install
npm run dev        # разработка с hot reload: http://localhost:5173/dark-counter/
npm run typecheck  # проверка типов
npm test           # юнит-тесты
npm run build      # сборка в dist/
npm run preview    # проверить сборку, PWA и офлайн: http://localhost:4173/dark-counter/
```

## Деплой на GitHub Pages
Деплоит GitHub Actions (`.github/workflows/deploy.yml`): на каждый PR — typecheck, тесты и сборка, на push в `main` — ещё и публикация.
Один раз: Settings → Pages → Source: **GitHub Actions**.
Адрес: `https://<username>.github.io/dark-counter/`. Если репозиторий переименуют, поменяйте `base` в `vite.config.ts`.

## Обновление игры
1. Ветка → изменения → `npm run typecheck && npm test && npm run build`.
2. PR → мердж в `main`, Actions задеплоит сам.
3. Версию кэша поднимать не нужно: Workbox сам видит изменившиеся файлы. Телефон подтянет новую версию со второго запуска.

## Перенос сохранения
Кнопка «сейв» в шапке даёт код сохранения. Скопируйте его и вставьте в поле загрузки на другом устройстве. Так же делается бэкап: код можно хранить в заметках.
