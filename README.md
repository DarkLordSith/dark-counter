# Тёмный прилавок

Пиксельный киберпанк-симулятор лавки на космической станции. Это личный упрощённый клон Probably Stolen.

Вы сидите за прилавком на нижнем ярусе станции. Зовёте клиентов, осматриваете товар, торгуетесь, чините и собираете вещи на верстаке. Вечером копаете на свалке, раз в несколько дней платите аренду ростовщику Гробову. Цель — накопить на выкуп лавки.

## Стек
- Один файл `index.html`: HTML, CSS и чистый JS без сборки и фреймворков.
- Графика рисуется в `<canvas>` прямоугольниками, музыка генерируется через Web Audio API.
- PWA: `manifest.webmanifest` и `sw.js` позволяют поставить игру иконкой на телефон и играть офлайн.
- Прогресс хранится в `localStorage` браузера.

## Запуск локально
Service worker работает только через http, поэтому нужен локальный сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Деплой на GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
Через минуту игра будет доступна по адресу `https://<username>.github.io/<repo>/`.

## Обновление игры
1. Изменить `index.html`.
2. Поднять версию `CACHE` в `sw.js`, например `dark-counter-v7`. Без этого телефон может показывать старую версию.
3. Закоммитить и запушить. Новая версия подтянется со второго запуска.

## Перенос сохранения
Кнопка «сейв» в шапке даёт код сохранения. Скопируйте его и вставьте в поле загрузки на другом устройстве. Так же делается бэкап: код можно хранить в заметках.
