# Бот баланса

Бот играет полные партии режима «Начало конца» (`story`, 60 дней) на чистых правилах игры (`src/economy.ts`) и сидируемом генераторе `mulberry32`. Один сид — одна и та же партия. Нужен, чтобы видеть, как правка чисел в `data.ts` меняет исход игры, без ручного плейтеста.

## Запуск

```bash
npm run sim                                   # все стратегии, 1000 сидов
npm run sim -- --seeds 1000 --strategy careful
npm run sim -- --strategy greedy --json tests/sim/out/greedy.json
```

- `--seeds N` — сколько партий (сиды 1…N), по умолчанию 1000. 1000 партий занимают ~1 с.
- `--strategy careful|owner|greedy|all` — по умолчанию `all`.
- `--json путь` — куда записать сводку, по умолчанию `tests/sim/out/sim.json`. Папка `out/` в `.gitignore`.

Вывод — таблица в консоль:
- доли концовок «улетел / остался / выселен»;
- доля партий с закрытым долгом, средний и медианный день закрытия;
- средний день выселения;
- доход в неделю: заработанные кредиты плюс погашенный долг;
- к дню 36 (точка плейтеста владельца): закрытая доля долга и чистый темп, кр./день (погашенный долг плюс прирост кредитов);
- покупок у продавцов на одну продажу покупателю;
- склад на утро, находки и их ценность за визит свалки;
- доля находок свалки, проданных в течение недели после раскопки;
- доход в неделю с обычных продаж и с оптовика, доля оптовика в доходе с продаж, сколько оптовиков и вещей им за партию (критерии задачи 36 у `owner`: склад на утро ≤ 10, находок за неделю ≥ 70%, обычные продажи ≥ ~3500 кр./нед., доля оптовика ≤ ~25%);
- кредиты и долг на конец каждой недели.

## Стратегии (`STRATEGIES` в `sim.ts`)

| | осторожный (`careful`) | «как владелец» (`owner`) | жадный (`greedy`) |
|---|---|---|---|
| осмотр | все три проверки | не смотрит | не смотрит |
| покупает | до 75% оценки | до 50% оценки | до 95% оценки |
| продаёт | по самой высокой цене с Чуйкой ≥ 60% | с Чуйкой ≥ 35% | с Чуйкой ≥ 40% |
| собирает по рецептам | нет | всё, что может, сначала дорогое | нет |
| свалка | до полуночи | до полуночи | и за полночь (все 6) |
| досрочный взнос | всё сверх платежа + 1000 | всё сверх платежа + 1000 | всё сверх платежа + 150 |

`owner` откалиброван по плейтесту владельца 16.11 (долг 25 000, день 36: закрыто 46% долга, темп ~370 кр./день). На тех числах и старом потоке клиентов бот давал 46,2% и 354 кр./день. На нём подбирается баланс, `careful` и `greedy` — границы.

Оптовику (задача 36) все стратегии продают одинаково: кладут в корзину вещи его группы от дешёвых к дорогим, пока влезает бюджет. Если без скидки влезает меньше двух вещей, берут −10%.

Все стратегии вечером чинят дефект и вычищают ИИ, если хватает запчастей. Запчасти, когда их мало, докупают на барахолке. Гробову бот платит, если хватает денег, иначе берёт отсрочку, иначе отдаёт залог, иначе его выселяют. Место на шаттле покупает, как только может.

Запас перед досрочным взносом сильно влияет на исход. Досрочный взнос уменьшает долг, но не следующий платёж, а платёж растёт на `DEBT.paymentStep` каждую неделю. С маленьким запасом лавке не на что закупать товар.

## Подбор баланса

```bash
npm run sim:grid                              # сетка долг 12–16 тыс., 500 сидов
npm run sim:grid -- --debts 12000-22000 --seeds 500
```

Перебирает долг (шаг 1000) × шаг платежа {150, 200, 250} × место {1500, 2000} + {50, 100} × день. Каждый вариант играют `owner`, `careful` и `greedy`. Таблица отсортирована по «мимо»: насколько вариант не попал в критерии (0 — попал во все):
- `owner` улетает в 60–80% партий;
- медианный день закрытия долга у `owner` — 48–55;
- `careful` выселяется не больше чем в 10%;
- `greedy` улетает не во всех партиях.

Числа `DEBT` бот подменяет на время прогона (`withBalance` в `sim.ts`) и возвращает обратно. Игра `DEBT` не меняет.

## Как устроено

- `sim.ts` — бот и сводка. Без Node API, его же импортирует смоук-тест `tests/unit/sim.test.ts`, который входит в `npm test`.
- `run.ts` — командная строка.
- `grid.ts` — подбор баланса по сетке.
- `register.mjs` + `loader.mjs` — Node 22 сам выполняет TypeScript, отбрасывая типы. Хук только дописывает `.ts` к импортам вида `./data`. Зависимостей не нужно.
- Типы проверяет `npm run typecheck` (`tests/sim/tsconfig.json`).

Новая стратегия — ещё одна запись в `STRATEGIES`.
